## 📌 Sobre o Projeto
Este projeto consiste em um mini game interativo desenvolvido para a disciplina de Desenvolvimento Web. O objetivo é demonstrar a manipulação do DOM em JavaScript utilizando o método `document.getElementById`.

## 🎮 Como Funciona
- O usuário clica no botão "INICIAR JOGO" para começar uma contagem regressiva de 10 segundos.
- Uma bolinha aparece em posições e cores aleatórias dentro da área de jogo.
- Cada clique/toque na bolinha contabiliza pontos e a move para uma nova posição.
- Ao final do tempo, o resultado total de pontos é exibido na tela.

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estruturação da página e elementos interativos.
- **CSS3**: Estilização, layout responsivo e transições.
- **JavaScript**: Lógica do jogo, temporizadores e eventos DOM (`getElementById`, `addEventListener`).
